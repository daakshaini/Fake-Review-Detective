# 🔍 Fake Review Detective

**An NLP and Machine Learning Web Application for Hotel Review Analysis**

Fake Review Detective is a Data Science project that uses Natural Language Processing (NLP), TF-IDF feature extraction, and a trained Linear Support Vector Machine (SVM) classifier to identify linguistic patterns associated with truthful and potentially deceptive hotel reviews.

## 🌐 Live Demo

**Live Application:** https://fake-review-detective-07.streamlit.app/

**GitHub Repository:** https://github.com/daakshaini/Fake-Review-Detective

## ✨ Features

- **Single Review Analysis:** Enter a hotel review and obtain a machine-learning prediction.
- **SVM Decision Score:** View the decision score generated by the classifier.
- **Explainable AI:** Explore TF-IDF feature contributions that influence the prediction.
- **Model Performance Dashboard:** Compare the recorded performance of multiple classifiers.
- **Confusion Matrix:** Examine correct and incorrect predictions from the held-out test set.
- **Cross-Validation:** View five-fold cross-validation metrics and fold accuracies.
- **Bulk Review Analysis:** Upload a CSV file containing multiple reviews and classify them in one batch.
- **Prediction Summary:** View the number of reviews classified as likely truthful or potentially deceptive.
- **CSV Export:** Download bulk analysis results, including predictions and decision scores.
- **Sample CSV Template:** Use a sample template to prepare a compatible input file.

## 📊 Dataset

The project uses a labeled hotel-review dataset containing the following fields:

- `deceptive`
- `hotel`
- `polarity`
- `source`
- `text`

### Dataset Summary

| Dataset Information | Count |
|---|---:|

The review text is cleaned and prepared for feature extraction. The dataset is divided into training and test sets to evaluate model performance on held-out examples.

## 🧹 Data Preprocessing

The preprocessing workflow includes:

1. Inspecting dataset structure and data types.
2. Checking missing values and duplicate records.
3. Removing duplicate reviews.
4. Converting text to lowercase.
5. Preparing the review text for feature extraction.
6. Splitting the dataset into training and held-out test sets.

## 🔤 TF-IDF Feature Extraction

Term Frequency-Inverse Document Frequency (TF-IDF) converts review text into numerical features that can be processed by a machine-learning algorithm.

The original feature-extraction experiment used a maximum vocabulary of 5,000 features and included unigrams and bigrams.

The TF-IDF transformer is saved as part of the trained pipeline so that new reviews are transformed consistently during prediction.

## 🔎 Explainable AI

The application provides a feature-contribution explanation for the Linear SVM prediction.

For each submitted review, the application:

- Transforms the review into TF-IDF features.
- Obtains the fitted Linear SVM coefficients.
- Calculates the contributions of features present in the review.
- Displays features that move the decision score toward the predicted class.
- Displays features that push the decision score in the opposite direction.

These contributions help explain the model's behavior. They do not prove that a specific word or review is truthful or deceptive.

## 📂 Bulk Review Analysis

The bulk analysis module supports processing multiple hotel reviews from a CSV file.

### Workflow

1. Download the sample CSV template from the application.
2. Prepare a CSV file containing the expected review-text column.
3. Upload the file through the Bulk Review Analysis section.
4. Run batch prediction using the existing TF-IDF and Linear SVM pipeline.
5. Review the prediction table and summary counts.
6. Download the results as a CSV file.

The results include the model's prediction and SVM decision score for each processed review.

Bulk predictions are not an evaluation dataset. Accuracy cannot be calculated from the predictions alone unless the true labels are available and an appropriate evaluation is performed.


## ⚠️ Limitations

- The model was trained on a particular hotel-review dataset and may perform differently on unrelated review domains.
- Truthful reviews may be misclassified, and deceptive reviews may be missed.
- Positive or negative sentiment is not proof of truthfulness or deception.
- The model cannot independently verify whether a reviewer stayed at a hotel.
- It cannot independently verify factual claims made in a review.
- The SVM decision score is not a probability or calibrated confidence percentage.
- Feature contributions explain aspects of the model's decision but do not establish the review's actual truthfulness.
- Recorded test metrics do not guarantee equivalent performance on future or unrelated reviews.
