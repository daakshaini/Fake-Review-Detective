# 🔍 Fake Review Detective

**An NLP and Machine Learning Web Application for Hotel Review Analysis**

Fake Review Detective is an academic Data Science project that uses Natural Language Processing (NLP), TF-IDF feature extraction, and a trained Linear Support Vector Machine (SVM) classifier to identify linguistic patterns associated with truthful and potentially deceptive hotel reviews.

The application provides an interactive interface for analyzing individual hotel reviews, processing multiple reviews through CSV uploads, viewing model performance metrics, and exploring feature contributions that influence predictions.

- **Live Application:** https://fake-review-detective-07.streamlit.app/
- **GitHub Repository:** https://github.com/daakshaini/Fake-Review-Detective

## ✨ Key Features

- **Single Review Analysis:** Enter a hotel review and obtain a machine-learning prediction.
- **SVM Decision Score:** View the decision score generated by the classifier.
- **Explainable AI:** Explore TF-IDF feature contributions that influence the prediction.
- **Model Performance Dashboard:** Compare recorded results from multiple classification algorithms.
- **Confusion Matrix:** Examine correct and incorrect predictions from the held-out test set.
- **Cross-Validation:** View recorded five-fold cross-validation metrics and fold accuracies.
- **Bulk Review Analysis:** Upload a CSV file containing multiple reviews for batch classification.
- **Prediction Summary:** View the number of reviews classified as likely truthful or potentially deceptive.
- **CSV Export:** Download bulk analysis results, including predictions and decision scores.
- **Sample CSV Template:** Use the application's sample template to prepare compatible input data.
- **Interactive Web Interface:** Access review analysis and model information through Streamlit.

## 🧹 Data Preprocessing

The data-preparation workflow includes:

1. Inspecting the dataset structure and column data types.
2. Checking for missing values and duplicate records.
3. Removing duplicate reviews.
4. Converting review text to lowercase.
5. Preparing cleaned text for feature extraction.
6. Splitting the dataset into training and held-out test sets.

The fitted preprocessing and feature-extraction steps are included in the saved pipeline to maintain consistent transformations during prediction.

## 🔤 TF-IDF Feature Extraction

Term Frequency-Inverse Document Frequency (TF-IDF) converts textual reviews into numerical feature vectors that machine-learning algorithms can process.

The original feature-extraction experiment used a maximum vocabulary size of 5,000 features and included unigrams and bigrams.

- **Unigrams:** Individual words.
- **Bigrams:** Consecutive two-word combinations.
- **TF-IDF weighting:** Represents words according to their frequency within a review and their distribution across the dataset.

The TF-IDF transformer is stored as part of the trained pipeline, allowing new reviews to be transformed consistently during prediction.

## 🤖 Machine Learning Models

The project evaluated three supervised classification algorithms:

1. Logistic Regression
2. Multinomial Naive Bayes
3. Linear Support Vector Machine (SVM)

### Recorded Held-Out Test Results

The following table records the results from the original model-comparison experiment.

| Model | Accuracy | Precision | Recall | F1-Score |
|---|---:|---:|---:|---:|
| Logistic Regression | 88.75% | 86.90% | 91.25% | 89.02% |
| Multinomial Naive Bayes | 86.88% | 83.91% | 91.25% | 87.43% |
| **Linear SVM** | **90.00%** | **89.02%** | **91.25%** | **90.12%** |

Based on these recorded results, the original Linear SVM pipeline was selected for the application.

### Performance Metrics Explained

- **Accuracy:** The proportion of all predictions that are correct.
- **Precision:** The proportion of predicted positive-class examples that are actually positive.
- **Recall:** The proportion of actual positive-class examples identified by the model.
- **F1-Score:** The harmonic mean of precision and recall.

The interpretation of precision and recall depends on how the dataset's truthful and deceptive labels are encoded.

## 🔎 Explainable AI

The application provides feature-contribution explanations for Linear SVM predictions.

For a submitted review, the explanation workflow can:

1. Transform the review into TF-IDF features.
2. Access the fitted Linear SVM coefficients.
3. Calculate feature contributions for features present in the review.
4. Display features that move the decision score in one direction.
5. Display features that influence the score in the opposite direction.

These contributions help explain aspects of the classifier's behavior. They do not prove that an individual word or review is truthful or deceptive.

## 📂 Bulk Review Analysis

The Bulk Review Analysis module supports batch processing of hotel reviews from CSV files.

### Workflow

1. Download the sample CSV template from the application.
2. Prepare a CSV file containing the expected review-text column.
3. Upload the file through the Bulk Review Analysis section.
4. Run predictions using the existing TF-IDF and Linear SVM pipeline.
5. Review the prediction table and summary counts.
6. Download the processed results as a CSV file.

The exported results include predictions and SVM decision scores for processed reviews, as supported by the application.

**Important:** Batch predictions are not model-evaluation results. Accuracy cannot be determined from predictions alone without ground-truth labels and a suitable evaluation procedure.

## 🚀 How to Run Locally

### Prerequisites

- Python installed on your computer.
- Git installed for cloning the repository.
- The project files and saved model pipeline.

### 1. Clone the Repository

```bash
git clone https://github.com/daakshaini/Fake-Review-Detective.git
cd Fake-Review-Detective
```

### 2. Create a Virtual Environment

For Windows PowerShell with Python 3.13 installed:

```powershell
py -3.13 -m venv venv
```

If Python 3.13 is not installed, use an installed Python version compatible with the project's dependencies and saved model.

### 3. Activate the Virtual Environment

```powershell
.\venv\Scripts\Activate.ps1
```

### 4. Install Dependencies

```powershell
python -m pip install -r requirements.txt
```

### 5. Run the Application

```powershell
streamlit run app.py
```

The local application normally opens at:

http://localhost:8501

Use compatible Python and package versions when loading the saved model pipeline.

## ⚠️ Limitations

- The model was trained on a particular hotel-review dataset and may perform differently on other review domains.
- Truthful reviews may be misclassified, and deceptive reviews may be missed.
- Positive or negative sentiment is not proof of truthfulness or deception.
- The model cannot independently verify whether a reviewer stayed at a hotel.
- It cannot independently verify factual claims made in a review.
- The SVM decision score is not a probability or calibrated confidence percentage.
- Feature contributions explain aspects of the model's decision but do not establish a review's actual truthfulness.
- Recorded test metrics do not guarantee equivalent performance on future or unrelated reviews.
- The dataset's composition and labeling may limit how well the model generalizes to real-world reviews.
